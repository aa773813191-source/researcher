# Researcher — Academic Profile Website

This is a bilingual static website for Amatalelah Abdulazez Mashhor Al-Ahdel.

## Included
- `index.html`: responsive English/Arabic academic profile
- `robots.txt`: allows search-engine crawling
- `sitemap.xml`: starter sitemap (update after the final public URL is known)
- `statnova_profile_patch.txt`: small Streamlit addition for an in-app researcher profile page

## Publish using GitHub Pages
1. Sign in to the GitHub account that owns `aa773813191-source/statnova`.
2. Create a **new public repository** named `researcher`.
3. Upload the contents of this folder to the repository root (make sure `index.html` is at the root).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main`, folder `/ (root)`, then Save.
7. GitHub will show the actual public URL in the Pages section. Do not assume the URL until GitHub displays it.
8. Open the URL and test both language buttons and the STATNOVA/DOI links.

## Search indexing
After publishing, submit the actual site URL and `sitemap.xml` in Google Search Console. Indexing is not immediate and cannot be guaranteed.

## Before public launch
- Confirm the spelling of the name against the journal's official author record.
- Add a professional contact email only if the owner wants it public.
- Add ORCID / Google Scholar / institutional profile links only after confirming the exact profile URLs.
- Do not add private phone numbers, home addresses, passwords, or account credentials.
- This package does not register or purchase a custom domain.
